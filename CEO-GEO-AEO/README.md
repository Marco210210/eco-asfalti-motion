[Privacy Policy](../public/privacy-policy.html) e [Cookie Policy](../public/cookie-policy.html).
Le vecchie versioni del modello, comprese copie Word/PDF e dati di altre aziende,
sono archiviate in `backups/seo-template-originale`, escluse da Git e dal sito.

Analytics non è necessario per l'indicizzazione e resterà spento fino alla
configurazione di un ID della proprietà Eco Asfalti e al consenso del visitatore.
Nessuna procedura garantisce una posizione, un tempo di indicizzazione o una
citazione nelle risposte AI.
